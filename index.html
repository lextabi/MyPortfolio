About

A production-focused engineer with a DevOps and automation mindset.

I'm a Manila-based Senior DevOps Engineer at Accenture with 8+ years of experience keeping enterprise applications healthy in production. Runling

2D running life-sim powered by real steps

Open testing · v0.20

Players build a runner that looks like them, then feed, train, and race it. Their real daily steps from Health Connect set the runner's fitness, so walking more makes them stronger.

  • Godot 4 client plus a custom Kotlin plugin that reads steps from Android Health Connect
  • Supabase backend (Postgres, email-code accounts) with a TypeScript edge function that owns all game rules and saves
  • Daily events with real players, simulated AI races, and an economy tuned with a 30-day balance model and a month-long fairness test that keeps walkers ahead of players who only pay
  • Social features: friends, clubs, chat, and live race rooms run on the server, which pays every runner with optimistic locking on each save
  • PowerShell build, release, and deploy scripts; Python tooling for versioning and asset sync

The Golden Compound

A click-to-chat funnel for a homemade garlic herb butter brand that sells by pre-order over Facebook Messenger. The page sells; the owner closes the order in chat.

  • Price list doubles as an order builder: + / − steppers, a running total, and a ready-made order message
  • Messenger links can't pre-fill text, so the order is copied to the clipboard with clear paste steps
  • Sticky phone bar shows the order total, plus Gmail and email-app fallbacks for non-Messenger users
  • Hosted on its own Azure Static Web App, deployed by a GitHub Actions workflow that runs only when its folder changes
