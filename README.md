# MyPortfolio

Personal portfolio website for Lex Joseph Tabi, Senior Software Engineer and DevOps Engineer.

## Overview

This is a static portfolio site designed for GitHub Pages. It highlights experience in warehouse management systems, DevOps release support, monitoring, automation, incident management, and cloud/application support.

## Files

- `index.html` - main portfolio page
- `styles.css` - site styling
- `script.js` - small interaction enhancements
- `assets/` - resume and visual assets

## Local Preview

Open `index.html` in a browser, or use the VS Code Live Server extension for a live preview.
